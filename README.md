# Quant-A-Maze 3.0 · Hackathon Submissions

Submit your project here before the deadline.

**Deadline:** DD Month YYYY, HH:MM AM/PM IST

## How to submit

1. Push your project to your own GitHub repository.
2. Click the **Issues** tab above, then **New issue**.
3. Choose **Hackathon submission** and fill in the form:
   - Team name
   - Link to your project repository
   - Demo video or live link (optional)
   - Track
   - Team members and their GitHub usernames
4. Click **Submit new issue**.

That's it. Each team submits **once**. If you need to change something, edit your issue before the deadline.

## Rules

- Your repository must be **public** until judging ends, or add the organizers as collaborators.
- Start your project after the hackathon begins. Judges will check your commit history.
- Include a README in your project repo explaining what it does and how to run it.
